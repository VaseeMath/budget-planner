# 💰 Budget Planner

A sleek, modern budgeting app to track your income and expenses.

## Features

- ✅ Add up to 50 income items and 50 expense items
- ✅ Categories for each item
- ✅ Frequency options: Weekly, Fortnightly, Monthly, Yearly, One-off
- ✅ Dashboard with summary cards and charts
- ✅ View all amounts converted to any frequency
- ✅ Pie chart expense breakdown by category
- ✅ Bar chart income vs expenses comparison
- ✅ Export to CSV and PDF
- ✅ Data saves locally in your browser
- ✅ Mobile responsive design
- ✅ Works offline once loaded

## Setup Instructions

1. Create a new repository on GitHub called `budget-planner`
2. Upload all files from this folder to the repository
3. Go to **Settings** → **Pages**
4. Under "Source", select **main** branch
5. Click **Save**
6. Wait 1-2 minutes, then visit your app at the URL shown

## Add to Home Screen (Phone)

### Android (Chrome):
1. Open the app URL in Chrome
2. Tap the menu (3 dots) → "Add to Home Screen"
3. Tap "Add"

### iPhone (Safari):
1. Open the app URL in Safari
2. Tap the Share button → "Add to Home Screen"
3. Tap "Add"

## Tech Stack

- React 18
- Tailwind CSS
- Recharts (charts)
- Lucide Icons
- localStorage (data persistence)

## Currency

All amounts are displayed in AUD (Australian Dollars).
